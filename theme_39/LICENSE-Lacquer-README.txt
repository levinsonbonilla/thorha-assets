Lacquer — Free Bootstrap 5 Nail Salon & Nail Bar Template by uiCookies
https://uicookies.com/

Lacquer is a chic, boutique two-page website template for nail salons and nail bars,
built on Bootstrap 5 with a sophisticated mauve and rose-gold palette. It includes a
full-screen hero, a dot-leader services & pricing menu, a filterable nail-art gallery
with a lightbox, a three-step online booking flow with validation, a technicians row,
a why-us block, a membership band, a retail shop, a testimonials slider, hours &
location, and an FAQ, plus a dedicated Services & Booking page. It is free for personal
and commercial use, completely jQuery-free (every interaction is vanilla JavaScript with
no plugins), progressively enhanced so all content shows with JavaScript disabled, and
fully responsive. Replace the demo images in img/ and the placeholder copy with your own
before going live.

WHAT'S INSIDE
  index.html          Home page (all sections)
  services.html       Full services menu + booking page
  css/vendor/         Bootstrap 5 (minified)
  css/style.css       Custom design layer (palette as CSS variables)
  js/vendor/          Bootstrap 5 bundle (includes Popper)
  js/main.js          Template behavior — vanilla JavaScript, no jQuery
  img/                Demo images (reference local paths)
