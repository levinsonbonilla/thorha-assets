Verdant — Landscaping & Lawn Care Bootstrap 5 Template

Verdant is a fresh, premium website template for landscaping, lawn-care and garden-design
companies. It includes two hand-built pages (a homepage and a detailed services/quote page)
with an instant-quote hero form, a working before/after slider, a lightbox project gallery,
transparent lawn-care pricing, animated stats, testimonials and an FAQ. It is free for both
personal and commercial use. Built on a self-hosted Bootstrap 5 with a heavy custom design
layer, it uses vanilla JavaScript only — no jQuery — and is fully responsive, accessible and
usable even with JavaScript disabled. Open index.html in any browser to get started; edit the
CSS custom properties at the top of css/style.css to recolor the whole site in seconds.
