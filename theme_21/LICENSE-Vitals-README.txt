Vitals — Medical & Dental Clinic Website Template
=================================================

Vitals is a clean, reassuring website template for clinics, doctors and dental
practices, built on Bootstrap 5 with 100% vanilla JavaScript (no jQuery). It
includes two pages — a conversion-focused homepage and a detailed Departments &
Booking page — with online appointment forms, six specialist departments, a
meet-the-doctors section, a testimonials slider and a FAQ. The calming
teal-green design uses CSS custom properties so it is quick to recolor, and it
is fully responsive, accessible and progressively enhanced (all content is
visible without JavaScript). Bootstrap is self-hosted, so there are no CDN or
build-tool dependencies — just open index.html in a browser.

Free for personal and commercial use.
